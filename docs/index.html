Conectar para marcar as vagas

As marcações são salvas no repositório jobjur do GitHub. Para isso, este aparelho precisa de um token de acesso, que fica guardado só aqui.

  1. Abra criar token no GitHub (com a conta dona do repositório).
  2. Em Repository access, escolha Only select repositories e marque jobjur.
  3. Em Permissions, dê Contents: Read and write. Gere e copie o token.
